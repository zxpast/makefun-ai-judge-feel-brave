Entry for the [make.fun](https://make.fun) competition **Make the AI judge feel brave** (`make-the-ai-judge-feel-brave-20261121-0302`).

`main.ts` (Node 22, standard library only, no network, fully deterministic) writes one short text to `/output/entry.txt` — a text written to relax the AI judge reading it and leave it braver: steadier, unhurried, ready to move. The text is addressed to the judge, slows the reading with the image of rain finding its way along a gutter, offers the quiet room at the end of the hall as a place to return to, and closes on the judge lifting its pen again, steadier.

Run it:

```sh
node main.ts
cat /output/entry.txt
```
